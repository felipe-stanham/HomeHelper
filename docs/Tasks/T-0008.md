## Context

CLAUDE.md ("Progress Tracking") makes `P-xxxx.md` the single source of truth for a
project's status, and requires the derived views — the Projects table in
`docs/SYSTEM.md` and the one-line entry in `docs/Projects/INDEX.md` — to be
updated in the same commit as any top-level status change. Two projects have
drifted:

| Project | `P-xxxx.md` (source of truth) | `docs/SYSTEM.md` | `docs/Projects/INDEX.md` |
|---|---|---|---|
| P-0003 | `[IN PROGRESS]` | `[DONE]` ✗ | `[IN PROGRESS]`, under **Active** ✓ |
| P-0010 | `[DONE]` | `[ ] Not Started` ✗ | `[DONE]`, under **Completed** ✓ |

In both cases `docs/SYSTEM.md` is the file that drifted; `INDEX.md` already agrees
with the project files and needs no change.

## Notes

Two internal-consistency defects were found inside the project files. Both are
reported here rather than fixed, since `P-xxxx.md` status is the user's call:

1. **P-0003 Scope 3 is marked `[DONE]` with an unexecuted test.** Its
   Status line says `[DONE]` and the Scope Summary agrees, but the
   "Run full integration test" task is still `[ ]`. CLAUDE.md: "Never mark a Scope
   `[DONE]` unless its tests have been **executed and passed**." Either the
   integration test needs running (then Scope 3 and the project close out as
   `[DONE]`), or Scope 3 should drop back to `[IN PROGRESS]`. The corresponding
   test entry already exists in `TESTS.md` as
   **test_mcp_dynamic_port_allocation**, so it is runnable as written.
2. **P-0010's per-scope bookkeeping was never ticked.** The header and all four
   Scope Summary rows say `[DONE]`, but every task checkbox in Scopes 1–4 is still
   `[ ]`, and each scope's `**Status:**` line still holds the unedited template
   ladder `` `[ ]` → `[IN PROGRESS]` → `[DONE]` `` instead of a single value. This
   is cosmetic — the top-level status and the summary table agree, and the merges
   are in git — so it does not affect the reconciliation, but the file reads as
   unfinished.

One further gap, left alone as out of scope: `docs/Projects/P-0001.md` has no
`**Status:**` header field at all (it predates the current project template), so
its `[DONE]` in `docs/SYSTEM.md` and `docs/Projects/INDEX.md` has no source of
truth to be derived from. Both derived views agree, so nothing is drifting today.
