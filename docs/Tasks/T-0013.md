### Defect 3 — two docs directories were tracked under the wrong case

Found while verifying ac-11, not in the original plan. Git's tracked paths disagreed with
CLAUDE.md and with the skills that read them:

| CLAUDE.md / skills use | Actually tracked as |
|---|---|
| `docs/Pitches/` | `docs/pitches/` |
| `docs/templates/` | `docs/Templates/` |

Invisible on macOS, where `core.ignorecase=true` and APFS is case-insensitive — which is why
it survived this long. On a case-sensitive checkout (both deploy hosts are Linux) the
consequences are real: the `Pitches/INDEX.md` link added to `docs/SYSTEM.md` in this task
would point at a directory that does not exist, the `pitch` skill writing to
`docs/Pitches/` would create a *second* directory alongside `docs/pitches/`, and the skills'
references to `docs/templates/PITCH_INDEX.template.md` would not resolve. Nothing at runtime
reads these paths, so there was no production impact — it is a docs-tooling defect only.

Renamed to CLAUDE.md's casing. Because `core.ignorecase=true` hides case-only renames from
git, the index needed a two-step `git mv` through a temporary name; a plain working-tree
`mv` updated the disk but left the index untouched.

### Defect 5 — the documented test command does not run

Found while verifying ac-12. `docs/SYSTEM.md` documented
`python3 -m pytest tests/ -v --tb=short --no-cov`, which fails at collection: the package is
not installed in the venv and `pytest.ini` is inert, so `import latarnia` resolves only
because 12 test modules each insert `src` into `sys.path` and pytest collects alphabetically.
The working command is `PYTHONPATH=src python3 -m pytest tests/ -q` → 486 passed, 1 skipped.

The documented command is corrected here. The underlying fragility is **not** fixed here —
repairing `pytest.ini`'s section header would activate `addopts` for the first time (coverage
plus asyncio auto mode), a behaviour change that has no business riding along with a
promotion. Filed as T-0016.
